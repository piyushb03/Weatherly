# 🌦️ Weatherly – Smart Weather Forecast App

Weatherly is a **Python-based desktop weather application** built using **Tkinter** and **OpenWeatherMap API**.  
It provides **current weather**, a **3-day forecast**, **AI-based weather tips**, **dark/light theme**, and an **on-demand temperature graph**, all wrapped in a clean and simple UI.

---

## ✨ Features

- 🌍 **Current Weather** (Temperature, Humidity, Condition)
- 📅 **3-Day Weather Forecast** (12 PM data)
- 🤖 **AI Weather Tips** (based on current temperature)
- 🌙 **Dark & Light Theme Toggle**
- 📊 **Temperature Graph** (opens only on button click)
- 📍 **Auto-Detect City** (IP-based)
- 🖥️ **Desktop Application (.exe supported)**

---

## 🛠️ Tech Stack

- **Python 3.13**
- **Tkinter** – GUI
- **Requests** – API calls
- **Matplotlib** – Graphs
- **OpenWeatherMap API**

## 📦 Installation

### 1️⃣ Clone the repository
```bash
git clone https://github.com/your-username/weatherly.git
cd weatherly
````

### 2️⃣ Install required dependencies

```bash
pip install requests matplotlib
```

---

## ▶️ Run the Application

```bash
python weatherly.py
```
